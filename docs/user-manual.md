# PartnerLedger 説明書

取引先・担当者・契約・名刺を1か所で管理し、大事な変更は承認を通してから反映するアプリです。この説明書は、アプリを使う人（利用者・承認者・PartnerLedgerの管理者）向けです。導入（インポート）の手順は[インポート手順書](import-guide.md)にあります。

> 2026-09-26時点の版です。画面の文言はこの時点のアプリに合わせています。

## 1. PartnerLedgerでできること

- 取引先（会社）、担当者（人）、契約を登録し、一覧で探せます。
- 名刺の画像を選ぶと、AIが読み取った内容を確認して、取引先・担当者として登録できます。
- 会社名や取引状態など、承認が必要な変更は「変更申請」になり、承認者が承認すると自動で反映されます。
- 取引先ごとに、誰が見られるか・編集できるかを「共有設定」で決められます。
- 契約の期限が近いときや、名刺が処理されずに残っているときは、毎朝メールで知らせます。

パソコンでもスマホでも、同じアプリをブラウザで使います（スマホで名刺を撮影する機能はありません。撮った写真を選んで登録します）。スマホは、SafariやChromeなどのブラウザでも、Power Appsのモバイルアプリでも使えます。Power Appsのモバイルアプリで開いている場合、アプリを新しい版にしたあとは、一度アプリを完全に終了してから開き直してください（古い版が残っていることがあります）。

## 3. 取引先

### 登録する

「新規登録」→「取引先を登録」で、会社名などを入れて登録します。登録したばかりの取引先は、取引状態が「未承認」になります。

登録すると、次の人がすぐに見られます。共有設定の作業は要りません。

- 登録した人（閲覧・編集）
- 主担当（登録した人と別の人なら、編集で共有されます。主担当が`PL 利用者`などのロールを持っていないと、ロールを割り当てられるまでは見られません）
- 承認者グループ（閲覧。この共有は外せません）

ほかの人に見せたいときは、下の「共有設定」で追加します。

### 詳細を見る

「取引先リスト」で行の左のボタンを押すと、詳細が開きます。詳細には4つのタブがあります。

| タブ | 内容 |
| --- | --- |
| 基本情報 | 業種・住所・代表電話・取引状態・主担当・登録者・登録日。ここから編集・変更申請をします |
| 契約・期限 | この取引先の契約と、契約終了日などの期限（[5章](#5-契約)） |
| 掲示板 | この取引先についての連絡事項（[10章](#10-掲示板と通知メール)） |
| 共有設定 | この取引先を見られる人・編集できる人 |

### 変える

「基本情報」の「取引先を編集」に、項目ごとのボタンが並びます。

- 「○○を編集」：その場で変更されます。
- 「○○を変更申請」：承認が必要な項目です。申請を出し、承認されると反映されます（[7章](#7-変更を申請する申請者)）。

どの項目に承認が必要かは会社の設定で決まり、「設定」の「承認が必要な変更」で確認できます（初期設定：会社名・取引状態・主担当・契約の更新・終了判断は承認が必要、住所・代表電話は直接変更。管理者が変更できます）。

**主担当を変える**：「主担当を変更申請」（または「主担当を編集」）で、新しい主担当を選びます。候補は、今の主担当を除いた利用者です。変わると、新しい主担当にはこの取引先の編集の共有が自動で付きます。前の主担当の共有はそのまま残るので、不要なら「共有設定」から外してください。

取引状態を「終了」にした取引先は、「アーカイブ」に移ります。

### 共有設定

「共有設定」タブで、この取引先を閲覧・編集できる人とグループを管理します。

- 共有先を検索して選び、アクセスレベル（閲覧・編集）を決めて追加します。
- 追加した共有先のアクセスレベルの変更や、取消もできます。
- 共有を管理できるのは、承認者グループと、その取引先を見られる人（登録した人・主担当・共有された人）です。
- 変更や取消ができるのは、自分と同じか低い共有だけです。閲覧だけの人は、編集を付けることも、編集の共有（主担当など）を外したり閲覧へ下げたりすることもできません。承認者グループの人は制限なしです。
- 承認者グループの共有は、誰も外せません。

## 4. 担当者

- 登録：「新規登録」→「担当者を登録」で、取引先を選び、氏名・在籍状態などを入れます。
- 変更：「担当者リスト」で担当者を開き、「担当者を編集」で変えます。
- 在籍状態を「退職」にすると、「アーカイブ」に移ります。
- **所属会社が変わった場合**は、その担当者を「退職」にして、新しい取引先で登録し直してください（担当者の取引先は変えられません）。

## 5. 契約

取引先の詳細の「契約・期限」タブで扱います。

- 「契約を登録」で、契約名・契約種類・契約終了日・解約通知期限・更新判断期限・自動更新・契約書リンクを登録します。契約種類がまだ無いときは、管理者に登録を頼んでください（[9章](#9-partnerledgerの管理者の操作)）。
- 締結済みの契約には、更新するか終了するかの判断を記録するボタンが出ます。承認が必要な設定なら「更新・終了判断を申請」、不要なら「更新・終了判断を登録」です。

## 6. 名刺から登録する

1. 「新規登録」→「名刺で登録」で、名刺の画像を選びます（一度に20枚まで）。
2. アプリが画像を受け付け、AIが読み取ります。読み取りには少し時間がかかります。
3. 「ホーム」の処理待ちに名刺が並びます。「確認する」を押すと、読み取った内容が開きます。
4. 内容を確認・修正して「確定する」を押し、取引先・担当者として登録します。
   - あなたが見られる取引先に同じ会社があるときは、「既存の取引先に担当者として追加」が選ばれた状態で候補が出ます。会社名が同じ取引先が1社だけなら、最初から選ばれています。選んで「担当者を追加する」を押すと、その取引先の担当者になります。
   - 同じ会社が見つからないときは、新しい取引先（未承認）と担当者を登録します。主担当を選んで「登録する」を押します。読み取りで社名の表記が少し違うこともあるので、「既存の取引先を名前で探す」から探し直せます。
   - 名前が同じでも、自動でまとめることはしません。どちらにするかは、確認した人が選びます。見られない取引先は候補に出ません。

読み取りに失敗した名刺には、「もう一度登録」（画像を選び直す）と「一覧から外す」（片付ける）が出ます。

## 7. 変更を申請する（申請者）

### 流れ

1. 取引先や契約の画面で「○○を変更申請」「更新・終了判断を申請」から、変更後の値を入れて申請します。
2. 承認者に承認依頼が届きます（Teams・Outlook）。
3. 承認されると、変更が自動で反映されます。却下されると反映されません。

申請の状態は「承認申請」の画面で確かめられます。上の「対応が必要／承認待ち／完了／すべて」で絞り込めます。

### 申請の状態

| 状態 | 意味 | 申請者ができること |
| --- | --- | --- |
| 下書き | まだ提出していない | 「提出する」、または「取り下げる」 |
| 提出中 | 承認者の判断待ち | 待つ（取り下げはできません。急ぎで止めたいときは管理者に取消を頼みます） |
| 反映済み | 承認され、変更が反映された | なし |
| 却下 | 承認者が却下した | 必要なら内容を見直して新しく申請 |
| 取消 | 取り下げた、管理者が取り消した、承認依頼に21日間応答がなかった、または承認依頼を作れなかった | 必要なら新しく申請 |
| 反映失敗 | 承認されたが、承認待ちの間に状況が変わったため反映しなかった | カードの「反映できなかった理由」を読み、今の内容を確かめてから必要なら申請し直す |

「承認済み」「反映待ち」は、承認から反映までの一瞬だけ表示されることがあります。

### 反映失敗になったとき

承認待ちの間に、申請した項目そのものが別の操作で変わった、承認の設定が変わった、または対象が無効になったときは、古い申請の内容で上書きしないように反映を止めます。申請は「反映失敗」になり、理由が画面に表示され、申請者にメールが届きます（メールにはアプリで申請を開くリンクがあります）。

住所や代表電話など、**申請していない項目**が承認待ちの間に変わっても、反映は止まりません。

### 知っておくこと

- **同じ取引先（契約）・同じ種類の申請は、1件が終わるまで次を出せません。** 二重の申請を防ぐためです。下書きを取り下げれば、すぐに出し直せます。
- 承認依頼に**21日間**応答がないと、申請は自動で「取消」になります。出し直してください。
- 承認依頼を作れなかったときも、申請は自動で「取消」になり、理由に「承認依頼を作れなかったため、自動で取り消しました」と出ます。もう一度申請してください。続くときは管理者に連絡してください。

## 8. 承認する（承認者）

### 承認依頼の見かた

承認依頼は、承認者グループのメンバー一人ひとりへ届きます（申請を提出した時点のメンバー。社外のゲストには届きません）。次のどこからでも確かめて応答できます。

- Outlookのメール（対応するOutlookなら、メールの中で承認・却下できます）
- Teamsの「承認」アプリ（通知も届きます。右上の環境の切り替えで、PartnerLedgerの環境を選んでください。既定の環境のままだと表示されません）
- Power Automateの承認センター

承認依頼には次の内容が載っています。

- 申請者
- 対象（取引先名、契約なら契約名と取引先名）
- 変更内容（項目ごとに「変更前 → 変更後」）
- 「PartnerLedgerで申請を開く」リンク（アプリで申請が一覧の先頭に表示されます）

件名は「申請の種類：対象の名前」（例：会社名の変更：青空商事）です。件名と変更内容は、提出時にPartnerLedgerが作るもので、申請者は書き換えられません。

### 応答する

「承認」または「却下」を選んで送信します（コメントは任意）。メールアプリによっては（スマホのブラウザで開くOutlookなど）、メールの中で応答できず、「Approve」「Reject」を押すと承認センターが開きます。そこで応答してください。まれに、承認依頼が承認者グループのアドレスあてに届くことがあります（メンバーを読めなかったとき）。そのときもメールの中では応答できないので、同じく承認センターかTeamsの「承認」アプリで応答してください。メールの「Requested by」は承認依頼を送る管理用のアカウントで、実際の申請者は本文の「申請者」です。グループの誰か1人が応答すると、その結果が反映され、ほかの人の依頼は閉じます。

### 気をつけること

- 申請者が取り下げた申請や、管理者が取り消した申請、21日で自動取消になった申請の承認依頼が、承認センターに残ることがあります。**応答しても反映されません。** 気になる場合は管理者に消してもらってください。
- 承認しても、承認待ちの間に申請した項目が変わっていた場合などは「反映失敗」になり、申請者に知らされます（[7章](#反映失敗になったとき)）。

## 9. PartnerLedgerの管理者の操作

`PL システム管理`のロールを持つ人の操作です。

| 操作 | 場所 | 内容 |
| --- | --- | --- |
| 提出中の申請を取り消す | 承認申請 → 申請のカード →「取り消す」 | 理由の入力が必要です。承認者が不在で進まないときなどに使います。取り消すと申請者が出し直せるようになります |
| 申請者が不在の下書きを取り消す | 同上 | 理由の入力が必要です |
| 契約種類を登録・変更する | 設定 → 契約種類 | 追加・名称変更・廃止ができます。契約種類が無いと契約を登録できません |
| 承認が必要な変更を変える | 設定 → 承認が必要な変更 | チェックを変えて「保存する」を押します。保存するたびに新しい版として記録されます。保存すると、承認待ちの申請は承認されても反映されず「反映失敗」に、差戻し中の申請は再提出できなくなります（取り下げて出し直してもらいます。保存の前に画面にも出ます）。ほかの管理者と同時に保存したときは「ほかの管理者が先に変更しました」と出るので、再読み込みしてから変更し直してください |

「取り消す」ボタンが出ない、承認設定のチェックが変えられないときは、`PL システム管理`がユーザーに直接割り当てられているかを、環境の管理者に確かめてもらってください（グループ経由の割り当てでは出ません）。

## 10. 掲示板と通知メール

### 掲示板

取引先と担当者の詳細に「掲示板」タブがあります。その取引先（担当者）を見られる人どうしで、連絡事項を投稿・閲覧できます（1回200文字まで）。投稿は後から編集・削除できません。

### 通知メール

毎朝、次の内容をメールで知らせます（宛先は導入時の設定によります）。

- 期限が近い契約（契約終了日の30日前、解約通知期限の7日前、更新判断期限の前日。契約名・取引先・期限の日付が載り、リンクからその取引先の「契約・期限」が開きます）
- 受け付けてから3日たっても処理されていない名刺（メールのリンクから、その名刺の確認画面を開けます）

承認された申請が反映できなかったときは、申請者にメールが届きます（[7章](#反映失敗になったとき)）。

## 11. 困ったとき・気をつけること

| こんなとき | どうする |
| --- | --- |
| 取引先が一覧に出てこない | その取引先が自分に共有されていない可能性があります。共有設定を管理している人（承認者グループなど）に頼んでください |
| 「○○を変更申請」を押すと申請できないと言われる | 同じ対象・同じ種類の申請が、下書きや提出中で残っていないか「承認申請」で確かめてください |
| 申請が「反映失敗」になった | カードの「反映できなかった理由」を読み、今の内容を確かめてから、必要なら申請し直してください |
| 提出した申請を取り下げたい | 提出中は取り下げられません。管理者に取消を頼んでください |
| 承認依頼が届かない（承認者） | Teamsの承認アプリで環境を切り替えたか確かめてください。それでも無ければ管理者に連絡してください |
| 承認依頼のリンクを開くと「リンクの申請が見つかりませんでした」と出る | その申請を見る権限が無いか、申請が無くなっています。管理者に確かめてください |
| 名刺が「読み取り失敗」になった | 「もう一度登録」で画像を選び直すか、「一覧から外す」で片付けてください |
| 契約を登録するボタンが無い | 契約種類がまだ登録されていません。管理者に登録を頼んでください |
| 担当者の会社が変わった | その担当者を「退職」にして、新しい取引先で登録し直してください |
